Session 0

How JavaScript Runs

Before the language, see where it runs and how you call it.

1What is JavaScript?

A programming language. It started in the browser to make pages interactive. With Node.js it also runs on servers, which is how backends are built.

2Way 1: In this page

Every code box in this guide has a Run button. The code runs inside your browser, and console.log prints below it.

Try it. Press Run.
Output appears here.

3Way 2: In a web page

Put your code inside a script tag in an HTML file. The browser runs it when the page opens. Open the browser console (F12) to see the console.log output.

index.html
<html>
  <body>
    <h1>My page</h1>

    <script>
      console.log("Hello from the browser");
    </script>
  </body>
</html>

Or keep the code in its own file and load it: <script src="app.js"></script>

4Way 3: With Node.js

No browser needed. Save your code in a file and run it from the terminal. This is how backend code and NestJS run.

app.js
console.log("Hello from Node.js");
Terminal
node app.js

5Write it, then call it

You will see this idea again and again. Writing a function only describes it. The code runs when you call it.

1. Write it (definition)function greet() {
  console.log("Hello");
}
2. Use it (call)greet();

Where to focus

If you already use Node.js and NestJS, do not spend weeks on basic syntax. Go deep on these:

  • Closures
  • The event loop
  • Promises
  • this
  • Prototypes
  • Memory management
