# technical-support

JavaScript basics in simple English, step by step. Every code example has a **Run** button, so you can see how JavaScript is called and what it prints.

Plain HTML, CSS and JavaScript. No install and no build step.

## Run it

Open `index.html` in a browser, or serve the folder:

```
python -m http.server 6700
```

Then open http://localhost:6700.

## Sessions

0. How JavaScript runs (in this page, in a web page, with Node.js)
1. Variables
2. Data types
3. Operators
4. Conditions
5. Loops
6. Functions
7. Arrays
8. Objects
9. Spread and rest
10. Promises and async/await
11. Important concepts
12. Learning roadmap

js/content/async.js      Session 10
js/content/concepts.js   Session 11
